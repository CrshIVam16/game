# Neon Snake

A responsive snake game made with vanilla HTML, CSS, and JavaScript.

## Play online

https://crshivam16.github.io/game/

## Run

Open `index.html` directly in a modern browser. No install or server is required.

## Play

Select **Start game**, then steer with the arrow keys or **W/A/S/D**. On small screens, use the on-screen direction pad. Press **Space** to pause or resume, and **R** or **Restart** to begin a fresh run. Eat the glowing food for 10 points; your best score is saved in your browser.
